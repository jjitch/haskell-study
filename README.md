# haskell-study

A minimal Haskell study repository with a devcontainer setup.

## Devcontainer

This repository includes a devcontainer configuration with the Haskell feature:

- `.devcontainer/devcontainer.json`

Open this repository in a devcontainer-capable editor (for example, VS Code with Dev Containers) to get a ready-to-use Haskell environment.

## Sample code

Sample file:

- `Main.hs`

Run the sample program:

```bash
runghc Main.hs
```

Or compile and run:

```bash
ghc Main.hs -o main
./main
```
